# خطة إطلاق LCAP — أسبوع البدء

> التواريخ الدقيقة تُثبت بعد اعتماد الراعي وتأكيد عودة الدكتور رائد. لا تنشر تاريخاً أو رابط تقديم قبل اختبار النموذج.

## اليوم 1 — اعتماد القرار
- اعتماد الاسم والنطاق والمدة والأدوار.
- تثبيت مسؤول البرنامج ومراجع القبول.
- اعتماد المجانية التأسيسية وشروط الدفعة.
- اعتماد إشعار الخصوصية وفترة الاحتفاظ.
- اعتماد بريد استقبال الإشعارات.

## اليوم 2 — تهيئة التقنية
- إنشاء Google Sheet خاص.
- إنشاء Cloudflare Turnstile.
- نشر Apps Script وإضافة Script Properties.
- ضبط رابط endpoint وSite Key في portal.html.
- اختبار إشعار المسؤول ورسالة تأكيد المتقدم.
- مراجعة صلاحيات Google Sheet.

## اليوم 3 — التحقق التشغيلي
- مراجعة معايير القبول وتوحيد rubric.
- إعداد قائمة مرشحين أولية داخلياً دون نشرها.
- دعوة المرشحين للورشة التعريفية.
- تجهيز سجل حضور الورشة.
- إعداد رسائل القبول والانتظار والاعتذار.

## اليوم 4 — ورشة الممثلين والسفراء
- تنفيذ ورشة 60–75 دقيقة.
- تسجيل الحضور والاهتمامات.
- اختيار ممثلين مبدئيين وتحديد نطاق دورهم.
- تحديد قنوات الإحالة دون مشاركة بيانات المتقدمين.

## اليوم 5 — فتح التقديم التجريبي
- نشر الرابط بعد نجاح جميع الاختبارات.
- فتح نافذة تقديم محددة.
- متابعة وصول الإشعارات يومياً.
- عدم مشاركة الطلبات خارج فريق التقييم.

## اليوم 6 — فرز الطلبات
- فحص الأهلية.
- تقييم الطلبات من مقيّمين عند الإمكان.
- توثيق الدرجة وسبب القرار.
- دعوة المرشحين لمحادثات الاختيار.

## اليوم 7 — تثبيت الدفعة
- اعتماد المقبولين وقائمة الانتظار.
- إرسال تعليمات الانضمام ونموذج خط الأساس.
- إسناد معرفات C01–C20 داخلياً.
- تثبيت موعد الانطلاق وأول لقاء جماعي.

## بوابة Go/No-Go
لا تفتح التقديم قبل تحقق كل ما يلي:
- [ ] موافقة الراعي على الإعلان والنطاق.
- [ ] بريد إشعارات معروف ومختبر.
- [ ] إرسال نموذج تجريبي ووصوله إلى جدول الردود.
- [ ] وصول إشعار المسؤول ورسالة تأكيد المتقدم.
- [ ] حماية Turnstile تعمل.
- [ ] صلاحيات الملف الخاص محصورة.
- [ ] إشعار الخصوصية ظاهر وواضح.
- [ ] فريق القبول يعرف rubric وآلية القرار.
- [ ] تاريخ البداية والجدول الأسبوعي مثبتان.
