# تفعيل استقبال LCAP والإشعارات

## ما هو جاهز في المستودع
- الواجهة العامة الحالية.
- بوابة نماذج متعددة: `portal.html`.
- Google Apps Script backend: `backend/Code.gs`.
- إشعار بريد للمسؤول عند كل إرسال، ورسالة تأكيد للمتقدم إذا أدخل بريده.
- حماية Turnstile (Cloudflare) قبل قبول الطلب.
- تخزين الردود في Google Sheet خاص، وليس داخل GitHub.

## ما يلزم قبل فتح الرابط للمتقدمين
لا تضع بيانات شخصية حقيقية قبل إكمال الخطوات والاختبار. لم يتم بعد ضبط بريد المستلم أو مفاتيح الخدمة أو نشر الـ Web App.

### 1) إنشاء ملف الردود الخاص
1. أنشئ Google Spreadsheet جديداً باسم `LCAP — Restricted Responses`.
2. لا تشاركه برابط عام. امنح الوصول فقط لمدير البرنامج والمراجع المعتمد.
3. انسخ Spreadsheet ID من الرابط.

### 2) إعداد Cloudflare Turnstile
1. أنشئ Widget لنطاق GitHub Pages الذي ستستخدمه.
2. احتفظ بـ Site Key (عام) وSecret Key (خاص).
3. لا تضع Secret Key في ملفات GitHub.

### 3) نشر Apps Script
1. افتح `script.google.com` وأنشئ مشروعاً.
2. انسخ `backend/Code.gs` وملف manifest.
3. من Project Settings > Script Properties أضف:
   - `ADMIN_EMAIL` = بريد المسؤول الذي يستقبل الإشعارات.
   - `TURNSTILE_SECRET` = المفتاح السري من Cloudflare.
   - `SPREADSHEET_ID` = معرّف ملف الردود الخاص.
4. Deploy > New deployment > Web app.
5. Execute as: Me. Who has access: Anyone. اختبر أولاً ببيانات تجريبية فقط.
6. انسخ Web App URL.

### 4) ربط الواجهة
في أعلى `portal.html` استبدل:
- `CONFIG.endpoint` برابط Apps Script المنشور.
- `CONFIG.turnstileSiteKey` بالمفتاح العام.
ثم انشر التعديلات على GitHub Pages.

### 5) اختبارات قبول إلزامية
- إرسال طلب تجريبي والتأكد من ظهوره في ورقة `application`.
- وصول إشعار إلى `ADMIN_EMAIL` مع رقم مرجعي.
- وصول رسالة تأكيد إلى بريد تجريبي للمتقدم.
- اختبار نموذج الاستقصاء الأسبوعي والمقابلة والمتابعة.
- رفض الطلب إذا فشل Turnstile.
- التأكد أن ملف الردود غير عام وأن غير المصرح لهم لا يستطيعون فتحه.
- حذف بيانات الاختبار قبل الإطلاق.

## من يستقبل ماذا؟
- المسؤول: كل إرسال، إلى البريد المحدد في Script Property باسم `ADMIN_EMAIL`.
- المتقدم: رسالة استلام إلى البريد الذي أدخله، مع رقم مرجعي.
- مدير البرنامج: يراجع الردود داخل Spreadsheet المقيد الصلاحيات.
- لا يتم إرسال الردود إلى الدكتور/المدربين تلقائياً؛ أضفهم إلى صلاحيات الملف فقط إذا اعتمدت ذلك.

## النماذج المقترحة
| النموذج | الغرض | التوقيت |
|---|---|---|
| application | التقديم والاختيار | قبل القبول |
| baseline | قياس خط الأساس والأهداف | الأسبوع الأول |
| weekly | متابعة المهام والعوائق | أسبوعياً |
| interview | تسجيل مقابلة ونتيجتها | عند وجود مقابلة |
| followup30 | قياس التقدم بعد 30 يوماً | بعد البرنامج |
| followup60 | قياس الاستمرار بعد 60 يوماً | بعد البرنامج |
| ambassador | ترشيح/تسجيل ممثلين وسفراء | قبل الإطلاق |

## الخصوصية والحوكمة
- اجمع الحد الأدنى من البيانات الضرورية فقط.
- لا تطلب رقم الهوية أو بيانات صحية أو مستندات حساسة.
- لا تضع روابط CV عامة؛ استخدم رابطاً خاصاً محدود الوصول، ويفضل تأجيل جمعه إلى مرحلة التأهل.
- مشاركة السيرة مع جهة توظيف تحتاج موافقة مستقلة محددة.
- حدد مدة احتفاظ واضحة ثم احذف البيانات عند انتهائها أو عند طلب الحذف حيث ينطبق.
- هذا إعداد تقني أولي وليس مراجعة قانونية؛ اعتمد إشعار خصوصية وشروط مشاركة قبل استقبال بيانات حقيقية.
