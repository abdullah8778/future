# تفعيل استقبال بوابة PMC LCAP عبر البريد

## قناة الاستقبال الحالية
تم ربط نماذج البوابة الخمسة بخدمة FormSubmit لإرسال الطلبات إلى:
- بريد الإدارة: Abdullah87a87@gmail.com
- Endpoint: FormSubmit AJAX.

لا تستخدم الواجهة Google Sheets أو Apps Script حالياً. ملفات Apps Script المرفقة محفوظة كخيار بديل لاحق وليست قناة الاستقبال النشطة.

## أول تفعيل — مطلوب من مالك البريد
1. افتح رابط البوابة المنشور وأرسل نموذج اختبار ببيانات وهمية فقط.
2. أول إرسال إلى عنوان جديد يطلب تفعيل البريد. افتح Gmail الخاص بالإدارة وابحث عن رسالة FormSubmit.
3. اضغط رابط **Activate Form** داخل رسالة التفعيل.
4. أعد إرسال نموذج اختبار، ثم تأكد من وصول تفاصيله إلى صندوق الوارد. افحص Spam أيضاً.
5. بعد نجاح الاختبار، أرسل رابط النموذج للمتقدمين.

قد يحتفظ المزود بمحاولات الإرسال قبل التفعيل لمدة تصل إلى 30 يوماً حتى يؤكد المالك البريد، وفق صفحة المساعدة الخاصة به. لا تعتمد على ذلك بدلاً من اختبار إرسال جديد بعد التفعيل.

## ما يصل إلى البريد
تُرسل أنواع النماذج الخمسة مع نوع النموذج، والحقول، ومعلومات مصدر الزيارة، والموافقات. يتضمن الإرسال honeypot وتسمية واضحة للموضوع. لا توجد حالياً رسالة تلقائية للمتقدم بعد الإرسال؛ واجهة البوابة تعرض النجاح فقط عند رد المزود بقيمة success=true.

## الخصوصية
- تُعالج البيانات عبر FormSubmit (formsubmit.co) لإيصالها إلى بريد الإدارة.
- تذكر وثائق FormSubmit أن بيانات الإرسال تحتفظ بها الخدمة لمدة 30 يوماً.
- يجب اعتماد إشعار الخصوصية ومراجعة ملاءمة مزود المعالجة ومتطلبات الأنظمة المحلية قبل الإعلان العام الواسع.
- لا تجمع بيانات صحية أو طبية أو أرقام هوية أو بيانات مرضى أو كلمات مرور أو معلومات دفع.
- لا يوجد رفع CV في نموذج التقديم الأولي.
- لا مشاركة مع جهة توظيف إلا بموافقة مستقلة وصريحة لاحقة.

## اختبار قبل النشر
- [ ] التأكد من فتح رابط HTML من خلال GitHub Pages أو خادم، وليس كملف محلي.
- [ ] تفعيل البريد عبر رسالة FormSubmit.
- [ ] اختبار application وdiscovery وopportunity وweekly وfeedback ببيانات وهمية.

- [ ] التأكد من ظهور رسالة الخطأ عند رفض الخدمة أو فشل الشبكة.
- [ ] حذف رسائل الاختبار من صندوق البريد بعد توثيق نجاحها.
- [ ] مراجعة الخصوصية والاحتفاظ وصلاحيات بريد الإدارة.
