# تفعيل بوابة PMC LCAP — قائمة الإطلاق

## الحالة
الواجهة والنماذج والخصوصية ومسودة Backend موجودة على فرع التطوير. **الاستقبال غير مفعّل** إلى أن تضبط الإدارة إعدادات Google وCloudflare وتنجح اختبارات End-to-End.

## 1) القرار بشأن قناة الاستقبال
الخيار الحالي: Google Apps Script + Google Sheets.
- المزايا: إعداد سريع، لا تحتاج خادماً مستقلاً، تكامل مباشر مع البريد وجداول Google.
- الحدود: حدود حصص Apps Script والبريد، تحكم محدود في CORS ومعدلات الطلبات، الاعتماد على إعدادات Google، ولا يوجد عنوان IP موثوق متاح في حدث doPost لتطبيق rate limit حسب IP.
- البديل قبل التوسع: خدمة نماذج/Backend مُدارة تدعم rate limiting وCORS وقواعد تحقق وسجلات تشغيل واضحة وموقع معالجة بيانات مناسب.
- Turnstile يقلل الإرسال الآلي لكنه لا يغني عن مراقبة الإساءة أو تحديد المعدلات في طبقة الخادم.

## 2) إنشاء Google Sheet خاص
1. أنشئ Spreadsheet باسم PMC LCAP — Restricted Responses.
2. لا تفعّل المشاركة العامة. امنح مدير البرنامج والمراجعين المصرح لهم فقط صلاحية الوصول.
3. احتفظ بالمعرف Spreadsheet ID خارج المستودع.

## 3) إعداد Cloudflare Turnstile
1. أنشئ Widget على نطاق GitHub Pages الفعلي.
2. احتفظ بالمفتاح العام Site Key والسر Secret Key.
3. لا تضع Secret Key في GitHub أو HTML.
4. اضبط ALLOWED_HOSTNAME على hostname الفعلي للموقع.

## 4) نشر Apps Script
1. أنشئ مشروعاً في Google Apps Script.
2. انسخ backend/Code.gs وbackend/appsscript.json.
3. أضف Script Properties التالية:
   - ADMIN_EMAIL = [SET BY TEAM: بريد الإشعارات]
   - TURNSTILE_SECRET = [SET BY TEAM: سر Turnstile]
   - SPREADSHEET_ID = [SET BY TEAM: معرّف الجدول]
   - ALLOWED_HOSTNAME = [SET BY TEAM: hostname دون https]
4. انشر Web App: Execute as Me، Access Anyone (لأن المتقدمين غير مسجلين). اختبر على بيانات وهمية فقط.
5. انسخ Web App URL.

## 5) ربط الواجهة
في portal.html حدّث CONFIG.endpoint وCONFIG.turnstileSiteKey بقيم الإنتاج. لا تضع أي Secret في الواجهة. تأكد أن Turnstile widget يقبل hostname الفعلي.

## 6) الموافقات والخصوصية قبل الإطلاق
- اعتماد نص privacy.html من مستشار قانوني/مسؤول خصوصية.
- تحديد مدة الاحتفاظ، بريد الخصوصية، وآلية طلب الوصول/التصحيح/الحذف: [SET BY TEAM].
- مراجعة موقع معالجة البيانات ومتطلبات نقلها ومزود الخدمة مع المستشار المختص.
- تأكيد نصوص الموافقة لكل نموذج.
- موافقة استخدام الشهادة اختيارية؛ لا تنشر أي شهادة قبل اعتماد النص النهائي.
- لا مشاركة مع جهة توظيف إلا بموافقة منفصلة لاحقة.
