# برنامج التمكين المهني للكفاءات المخبرية | LCAP

صفحة تعريف عامة ونموذج تقديم تجريبي تابعان لمجتمع السيطرة المهنية.

**الاسم الإنجليزي:** Laboratory Career Advancement Program (LCAP)  
**الاسم العربي:** برنامج التمكين المهني للكفاءات المخبرية  
**المدة المقترحة:** 8 أسابيع تطوير + متابعتان بعد 30 و60 يوماً.

## مكونات المشروع
- صفحة تعريف عامة.
- بوابة نماذج متعددة: تقديم، خط أساس، تحديث أسبوعي، مقابلة، متابعة 30/60 يوماً، وترشيح سفراء.
- Backend أولي باستخدام Google Apps Script مع إشعار بريد للمسؤول ورسالة تأكيد للمتقدم بعد ضبط الإعدادات.
- دليل التفعيل والخصوصية والاختبار في `ACTIVATION.md`.

## ما الذي تتضمنه الصفحة؟
- تعريف البرنامج والفئة المستهدفة.
- رحلة التطوير الأسبوعية.
- معايير المفاضلة وأوزانها.
- نموذج تقديم تجريبي يوضح البيانات المطلوبة.

## حالة نموذج التقديم
النموذج في هذه النسخة **واجهة معاينة فقط**. لا يرسل البيانات ولا يحفظها. لا تُعلن الصفحة كقناة تقديم فعلية ولا يُطلب من المتقدمين إدخال بيانات حقيقية قبل ربطها بخدمة استقبال آمنة ومختبرة.

### خطوة التفعيل المطلوبة
1. اختيار قناة استقبال خاصة وآمنة (نموذج مؤسسي أو backend محمي).
2. تحديد المسؤول المخول بالوصول إلى الطلبات والملفات.
3. اعتماد إشعار الخصوصية وفترة الاحتفاظ وآلية حذف البيانات.
4. اختبار الإرسال والاستلام والصلاحيات قبل فتح التقديم.
5. تحديث نموذج الصفحة وربط endpoint المعتمد، ثم إزالة رسالة المعاينة فقط بعد نجاح الاختبار.

## الحوكمة
- لا تُرفع أسماء المرشحين أو أرقام التواصل أو السير الذاتية أو تقييمات القبول إلى مستودع GitHub عام.
- لا تُشارك سيرة أي مشارك مع جهة توظيف دون موافقة مستقلة ومحددة.
- لا يوجد ضمان وظيفي؛ المخرجات هي تطوير الجاهزية والأدوات وقياس التقدم.
- تُنشر قصص النجاح بموافقة واضحة، مع وصف دقيق للنتيجة.
